### Universal Native Desktop Music Player (macOS Apple Silicon & Linux)

**Sonora** unites Spotify, YouTube Music, and Local files into one high-performance, glassmorphic desktop client.

#### Highlights
- **Deterministic Gapless Audio**: Symphonia + CPAL double-buffering pre-roll engine.
- **Loudness Normalization**: Real-time EBU R128 (-14.0 LUFS) hardware gain stage.
- **Synced Lyrics with Romanization**: Real-time LRCLIB synced lyrics with instant transliteration (Romaji, Hangul, Pinyin, Cyrillic).
- **Zero Electron Overhead**: <105 MB RAM idle (~7x-10x lighter than Spotify desktop).
- **Spotube-style Resolver**: Full Spotify library integration with high-bitrate streaming and zero DRM blocks.
