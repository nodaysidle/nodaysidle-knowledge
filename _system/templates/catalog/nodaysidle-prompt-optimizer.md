# Prompt Optimizer

Production-grade client-first prompt linting, rewrite, diff, and playground. Features full support for LLM prompts (`user`, `system`), diffusion image prompts (`image` for Google Nano Banana, GPT-1.5, Midjourney), and structured video prompts (`video` for Google Veo 3.1, Google Omni, Kling, Runway) with dual decision intelligence: **Microsoft-Decision-1** (primary via OpenRouter for 85ms median linting) and **TypeSafe Jev** (fallback), auditing temporal motion dynamics and camera paths.
