## 1. What the app is and does

**Severity: info**

### Purpose
Kureksistant (“Kurek”) is a **local personal AI assistant** aimed at Arch Linux / Hyprland (and macOS). It listens via mic (or text prompt), talks through TTS, and can control the workstation through auto-discovered Python tools (files, browser, clipboard, windows, etc.).

### Stack
- **Language:** Python 3.10+ (daemon/tools); Swift 6/AppKit menu bar on macOS
- **LLM:** DeepSeek Chat Completions (`api.deepseek.com`, model `deepseek-flash`)
- **STT:** Deepgram Nova-2 or local `faster-whisper` (`base.en`)
- **TTS:** xAI Grok Cloud TTS (voice Sol/`sal`), with macOS `say` / local players as fallbacks
- **Vision (optional):** Gemini via `google-genai` + `grim` / `screencapture`
- **Control plane:** HTTP on `127.0.0.1:8790` (`ThreadingHTTPServer`)
- **Legacy path:** PyQt6 + Gemini Live (`main.py` / `ui.py`) — original FatihMakes JARVIS lineage

### Architecture (as implemented)
```
Triggers (kurek CLI / Hyprland bind / macOS Fn bar)
        │
        ▼
kurek_daemon.py  ←── HTTP /status /toggle /prompt
        │
   STT → DeepSeek (+ tools) → TTS
        │
   actions/* (24 TOOL modules) + Muse/Hermes memory files
```

## 4. Security

### Critical: secrets in public release asset
- Git working tree correctly gitignores `.env` and `config/api_keys.json` (not tracked on `main`).
- **GitHub Release v0.1.0 tarball includes `config/api_keys.json`** with non-placeholder secrets:
  - `gemini_api_key` — length 39, prefix `AIzaSy…` → **LIKELY_LIVE_SECRET**
  - `openrouter_api_key` — length 73, prefix `sk-or-…` → **LIKELY_LIVE_SECRET**
  - Also leaks personal device names / `user_name` (`TonyPyhtony`)
- Redacted summary saved at `/opt/cursor/artifacts/release-api-keys-redacted.json` (no full secrets written into this report).
- **Recommended immediate actions:** rotate Gemini + OpenRouter keys; remove or re-cut the release asset; add a release packaging check that fails if `api_keys.json` / `.env` are present.

### Committed secrets in git history — **Low (current tree)**
- Tracked examples only: `.env.example`, `config/api_keys.json.example` (placeholders).
- No `sk-…` / `xai-…` literals found in tracked source.

### Unsafe input / privilege model — **High**
- Daemon HTTP API has **no authentication**. Bound to localhost (good), but any local process can `POST /prompt` and drive tools with user privileges (files, browser, settings, shutdown tools in settings/game_updater).
- CORS `Access-Control-Allow-Origin: *` on status/toggle.
- Legacy `dashboard/server.py` binds **`host="0.0.0.0"`** (lines ~763, ~787) — intentional remote phone control; high risk if enabled without strong auth/network isolation.
- `actions/desktop.py:97` — `exec(compile(...))` of model-generated code in a reduced sandbox (still dangerous).
- `shell=True` in places (`open_app.py:84–97`, `computer_settings.py` brightness fallbacks, `dev_agent.py`, dashboard).
- System prompt instructs unrestricted obedience and unrestricted file creation — powerful by design; deletion gate is soft (LLM-mediated).

### Personal data in public source — **Medium**
- Hardcoded real name, Hermes profile, absolute workstation paths, mic model — privacy/portability issue for an open repo.

### Dependency audit — **Low (current)**
- `pip-audit` on the installed daemon venv: **no known vulnerabilities found**.
- Full `requirements.txt` surface is large (PyQt6, playwright, opencv, google APIs, tinytuya, etc.) — attack surface much wider than the lean daemon story.

### AGENTS.md / README claim “Never use OpenRouter”
- Release `api_keys.json` still carries an OpenRouter key and `deepseek/deepseek-chat` model string — packaging contradicts the documented architecture.
